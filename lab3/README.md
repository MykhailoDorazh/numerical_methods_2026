# Лабораторна робота №3

**Тема:** знаходження алгебраїчних многочленів найкращого квадратичного наближення методом найменших квадратів.

Робота оформлена як №3 за уточненням студента. У вихідному файлі завдання надруковано №4.

## Запуск у Windows

Відкрийте PowerShell у цій папці й виконайте:

```powershell
py -m pip install -r requirements.txt
py main.py
```

Для запуску зі збереженням результатів без вікон графіків:

```powershell
py main.py --no-show
```

Програма працює з будь-якого поточного каталогу: шляхи до даних та результатів визначаються відносно `main.py`. Для іншого CSV можна використати `py main.py --data "C:\шлях\до\даних.csv"`.

## Файли

- `data.csv` - 24 середньомісячні температури з прикладу у завданні, а не спостереження з окремого метеорологічного джерела.
- `main.py` - повна програма, власні функції формування нормальної матриці й вектора, метод Гауса з вибором головного елемента в стовпці, схема Горнера, похибка та дисперсія.
- `lab3.ipynb` - виконаний блокнот Jupyter з поясненнями, результатами, графіками та незалежною чисельною перевіркою. Для повторного виконання за потреби встановіть Jupyter: `py -m pip install jupyter`, а потім відкрийте блокнот у VS Code або через `py -m jupyter lab`.
- `results.txt`, `results.json` - результати розрахунків та коефіцієнти.
- `processed/variances.csv` - MSE, RMSE, сума квадратів і максимальні вузлові похибки для m=1..10.
- `processed/node_errors.csv` - наближення й абсолютні похибки для кожного степеня в усіх 24 відомих вузлах.
- `processed/dense_errors.csv` - 481 точка табуляції та відхилення для m=1..10 від кусково-лінійної інтерполяції.
- `processed/coefficients.csv` - коефіцієнти у змінних t і x; порядок від вільного члена до старшого степеня.
- `processed/forecast.csv` - формальна екстраполяція на місяці 25, 26, 27 для всіх десяти моделей.
- `images/` - графіки, які відтворює програма.
- `assignment/lab3_26.pdf` - оригінал завдання.
- `Лаб3_Дораж.pdf` - готовий звіт.

## Як інтерпретувати результати

Для стійкості обчислень використано t=(x-12.5)/11.5. Це лінійна заміна змінної, яка не змінює простір апроксимуючих многочленів. Нормальні рівняння розв'язуються власним методом Гауса, а не бібліотечним розв'язувачем МНК.

У завданні є дві форми критерію: у теоретичній формулі використано δ=√(SSE/N), у псевдокоді - D=SSE/N. Програма виводить обидві величини: MSE у °C² і RMSE у °C. Мінімум у них досягається при однаковому m.

У вхідних даних 24 вузли (місяці 1..24) з кроком 1 місяць і 23 проміжками. Для додаткової табуляції застосовано наведене у завданні n=24 і h₁=(24-1)/(20·24)=23/480 місяця, тобто 481 точку з обома кінцями. Між вузлами справжню температуру не задано. Тому `dense_errors.csv` містить відхилення поліномів від явно обраного кусково-лінійного інтерполянта, а не невідому істинну похибку температури. Вузлові похибки в `node_errors.csv` обчислено без цього додаткового припущення.

Мінімальна навчальна MSE серед m=1..10 вибирає m=10. Вкладені поліноміальні моделі зазвичай зменшують навчальну похибку зі збільшенням степеня, тому цей критерій не перевіряє здатність до прогнозування. Формальна екстраполяція P₁₀ на наступні три місяці дає дуже великі значення, які не слід трактувати як надійний прогноз погоди. Для сезонних температур потрібна окрема модель сезонності та перевірка на відкладених даних; у цій роботі реалізовано саме поліноміальний алгоритм із завдання.
