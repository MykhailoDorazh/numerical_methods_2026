# Лабораторна робота №7

**Тема:** ітераційні методи розв'язування систем лінійних алгебраїчних рівнянь.

## Запуск у Windows

Відкрийте PowerShell у папці лабораторної та виконайте:

```powershell
py -m pip install -r requirements.txt
py main.py
```

Для збереження результатів без вікон графіків:

```powershell
py main.py --no-show
```

Щоб повторно згенерувати ту саму систему з фіксованим seed=2026:

```powershell
py main.py --regenerate --no-show
```

Програма використовує шляхи відносно власної папки, тому працює незалежно від поточного каталогу.

## Параметри й точність

Розмірність n=100, початкове наближення xᵢ⁽⁰⁾=1.0, відомий розв'язок x*ᵢ=2.5, точність ε=10⁻¹⁴. Критерії зупинки однакові для всіх методів і перевіряються одночасно: **‖Ax-b‖∞ ≤ ε** та **‖x⁽ᵏ⁾-x⁽ᵏ⁻¹⁾‖∞ ≤ ε**. Додатково перевіряється фактична похибка **‖x-x*‖∞ ≤ ε**. Нев'язка й похибка розв'язку є різними величинами; обидві наведено в результатах.

Норма вектора: maxᵢ|xᵢ|. Норма матриці: maxᵢ Σⱼ |aᵢⱼ|. При множенні матриці на вектор використано власний цикл із `math.fsum`, який зменшує втрати точності при підсумовуванні.

Позадіагональні елементи згенеровані рівномірно на [-1,1]/100. Діагональ визначається як сума модулів позадіагональних елементів у рядку плюс незалежний додатний запас на [0.25,0.5]. Помірний масштаб матриці дозволяє виконати абсолютний критерій 10⁻¹⁴ у звичайній подвійній точності. У файлах збережено 17 значущих цифр для відтворення чисел після зчитування.

Для простої ітерації обрано τ=1/maxᵢ aᵢᵢ. Завдяки додатній діагоналі та строгому переважанню це дає ‖I-τA‖∞<1. Для Якобі та Зейделя також явно перевірено норми матриць переходу ‖C‖∞<1. Кількість ітерацій та перевага одного методу стосуються цієї конкретної матриці, початкового наближення, τ та критерію зупинки.

В основних алгоритмах не використано готових розв'язувачів СЛАР.
