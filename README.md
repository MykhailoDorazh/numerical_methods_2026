# numerical_methods_2026

Лабораторні роботи з дисципліни «Методи та технології обчислень».

Автор: Михайло Дораж

## Структура

| Папка | Робота | Звіт |
|-------|--------|------|
| [lab0](lab0/) | Вступна: організація робочого середовища, основи Python і Git | [Markdown](lab0/report.md) |
| [lab1](lab1/) | Інтерполяція кубічними сплайнами (профіль висоти Заросляк → Говерла) | [PDF](lab1/report.pdf) |
| [lab2](lab2/) | Розділені різниці, многочлени Ньютона та факторіальні многочлени (варіант 1: прогноз часу виконання алгоритму) | [PDF](lab2/report.pdf) |
| [lab3](lab3/) | Метод найменших квадратів: поліноміальне наближення температур | [PDF](lab3/Лаб3_Дораж.pdf) |
| [lab4](lab4/) | Точність чисельного диференціювання, методи Рунге-Ромберга та Ейткена (швидкість зміни вологості ґрунту) | [PDF](lab4/report.pdf) |
| [lab5](lab5/) | Складова формула Сімпсона, Рунге-Ромберг, Ейткен, адаптивний алгоритм (навантаження на сервер) | [PDF](lab5/Лаб5_Дораж.pdf) |
| [lab6](lab6/) | LU-розклад та ітераційне уточнення розв'язку СЛАР (100 × 100) | [PDF](lab6/report.pdf) |
| [lab7](lab7/) | Ітераційні методи розв'язування СЛАР: проста ітерація, Якобі та Гаусс-Зейдель | [PDF](lab7/Лаб7_Дораж.pdf) |

Кожна лабораторна робота знаходиться в окремій папці `labN/` і містить програму `main.py` та звіт. До робіт також додані використані дані, отримані результати й графіки, якщо вони передбачені завданням. Назви PDF-звітів наведені в таблиці.

Для лабораторних 3 і 7 є окремі інструкції `README.md`. Блокнот `lab3/lab3.ipynb` є додатковим; основна програма запускається без Jupyter.

## Середовище

- Python 3.13
- PyCharm Community
- NumPy, Matplotlib, Requests
- Git

## Запуск

Відкрийте PowerShell у корені репозиторію та встановіть залежності:

```powershell
py -m pip install -r requirements.txt
```

Перейдіть у папку потрібної роботи й запустіть її, наприклад:

```powershell
cd lab7
py main.py
```

Для іншої лабораторної замініть `lab7` на відповідну папку. Звіти можна відкривати без запуску програм за посиланнями в таблиці.

Лабораторна 1 використовує Requests для отримання профілю висоти та містить збережений файл `elevation_data.json` для роботи за недоступності сервісу.
